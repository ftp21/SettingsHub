# SettingsHub

Plugin Enigma2 per installare e aggiornare canali/bouquet da diversi
"setting man", con un solo provider attivo alla volta.

## Provider inclusi

- Vhannibal (vhannibal.net)
- Morpheus883 (morpheus883.altervista.org)
- Andrea del 1984 (github.com/Andreadel1984/Liste-Canali-Enigma2-Italia)
- ManuTEK (manutek.it)
- Ciefp (github.com/ciefp/ciefpsettings-enigma2-zipped)

## Installazione

Copiare `usr/lib/enigma2/python/Plugins/Extensions/SettingsHub/` in
`/usr/lib/enigma2/python/Plugins/Extensions/SettingsHub/` sul decoder e
riavviare Enigma2. In alternativa, installare l'ipk da una release.
